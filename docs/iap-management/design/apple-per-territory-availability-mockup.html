Hub tracking: the stopped run finalizes with its own terminal status — not FAILED, because 34 items really did succeed. Retry remaining opens a genuinely new run (R3 multi-start hygiene). A tracking status must reflect the real outcome, never the button clicked.

Open questions carried into review (design doc §G): G6 custom-price × excluded territory is UNCERTAIN; baseTerritory defaults to USA and a USA-excluding selection is incoherent; Apple’s hourly cap figure is still unresolved (250 vs 3,600 — KB §4.9); surface A’s mode filter needs rethinking now that every item is a candidate; the remainder is client-held, not durable.
