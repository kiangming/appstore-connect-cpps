Export picker — pagination + shift-click range

Mockup for docs/iap-management/design-export-picker-paging-range.md. Apple IAP Management only. Step 2 (countries) is the shared ExportOptionsDialog — P8-locked, not redesigned, not shown.

Cost model (P1.6). Every exported item costs ~3 Apple requests (detail + price-schedule stage 1 + stage 2). Selecting fewer items saves real requests — the opposite of Google, whose export is one list call. Every control on this screen costs 0 requests; only the final Export reads Apple.
⚠ THE ONE THING THIS MOCKUP IS DESIGNED AROUND. Three bulk-select scopes coexist, and two of them used to look identical. (A) = all matching, every page — now a labelled button in the toolbar. (B) = this page only — the only checkbox in the tickbox column. (C) = shift-click range, within one page, no control of its own.
As-built note. Shipped in Y1 (b438556) + Y2. The Rows selector is a drop-down here, per the Manager’s one change to this mockup; everything else is as drawn. Scope is read from position, not from memory.
